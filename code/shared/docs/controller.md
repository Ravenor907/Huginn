# Using Huginn with a controller or TV remote

Huginn works with a game controller as well as a mouse and keyboard, which helps on a TV or a handheld. There is no
separate controller mode: the controller works in the normal layout, which follows the screen (one column upright,
the rail layout sideways). Huginn checks for a controller only while one is connected.

The button legend along the bottom is hidden at first. Press **Select** (View or Back) to show it, and Select again,
or any other button, to hide it. Hints about buttons only show while a controller is in use.

| Button | What it does |
|---|---|
| D-pad | Move the highlight, from the last thing highlighted or clicked |
| A | Open, choose, or write a message |
| B | Back |
| Y (hold) | Record a voice message |
| LB | Next section (hold LB and press D-pad left or right to go back or forward) |
| LT | Options: message options, Send a picture, Call and more |
| Left stick | Scroll |
| Right stick | Move the pointer (it hides after a few seconds) |
| RB or R3 (right stick click) | Click |
| RT | Right click |
| Select (View) | Show or hide the button legend |
| Menu | Settings |
| L3 + R3 (hold) | Panic lock (Ctrl+Shift+Q on a keyboard) |

The pattern lock works with the D-pad: move to a dot, A starts there, move on through the dots, A again when done. B starts over.

A mouse and keyboard work too (Tab and Shift+Tab switch sections, Page Up and Page Down scroll).

## The desktop panels

Sideways, Huginn looks like Discord: the rail, the list beside it, the conversation and a group's member list.
Everything there works with a controller too:

- D-pad left and right move between the list, the conversation and the member list. A hidden list or member
  list (Ctrl+Shift+L, Ctrl+Shift+U) opens again while the controller's highlight is in it.
- A on a member opens their profile card (Message, Call, Video, nickname, note, folders). The D-pad moves along
  its buttons and B closes it. An admin finds Group options there.
- A on a TEXT or VOICE heading folds that category away, and A again opens it.
- In a voice room, A on the room has Mute, Deafen and Leave. The voice panel at the foot of the list has them too
  (click it with the right stick's pointer).
- Push to talk (Settings › Calls) is a keyboard key: it works while Huginn is in front.

## Calls and files

- In a call, A mutes, Y changes the output and B ends the call. B asks first: the first press shows "Press B again
  to hang up" for 3 seconds, and a second press in that time hangs up. On a voice call X does the same as B; on a
  video call X turns the camera on or off. On a keyboard, Esc or Backspace is B and Space mutes.
- In Files, Direct connect is a row under Pick files to send and Clear the list: move to it with the D-pad and press A.
  While files are being sent, B asks first too ("Press B again to cancel").

Ctrl+/ lists every keyboard shortcut.
